# planteam development

- Added a checkout-based Quarto catch report workflow with explicit local CSV inputs, example mode, HTML and Word output, selected-data export, and a provenance record. Existing package functions and R Markdown templates are unchanged.

- Added a local Shiny SAFE introduction builder with BSAI/GOA stock and subsection editing, TODO boilerplate, atomic JSON saves/backups, copy/cut/paste undo, and Quarto HTML/Word/PDF rendering.

- Added double-click Start/Stop launchers backed by an on-demand macOS service, with startup health checks and persistent logs, so the builder survives task completion without automatic boot/login startup.
